Consumer CAD AI | Windows 10 / 11 x64 通用免安装版

本压缩包已内置完整环境（Python 3.12 + CAD/MCP 全套依赖 + FreeCAD 1.1.2），
无需额外安装 Python 或 FreeCAD，也不绑定任何特定 AI 客户端。

【三步极速上手】

1. 解压到短路径
   在 Windows 里右键 ZIP，选择“全部解压缩”，建议放到本地磁盘短路径（例如 C:\CAD）。

2. 离线生成并查看 3D 成品（无需 AI 即可体验）
   - 双击 Run-Demo.cmd：自动生成“铝合金桌面手机支架”及全套工程文件，
     并自动打开 outputs 里的结果文件夹。
   - 双击 Open-FreeCAD.cmd：启动内置 FreeCAD 图形界面，拖拽或打开结果里的
     assembly.FCStd 即可 3D 查看模型。

3. 一键接入 WorkBuddy 或任意 AI Agent
   - 双击 Setup-Agent.cmd：自动按当前解压路径生成 mcp.json 和 .mcp.json，
     并将标准 MCP 配置复制到剪贴板。
   - WorkBuddy 用户：
     在 WorkBuddy 左侧打开“连接器” -> “自定义连接器” -> 类型选 stdio，
     直接粘贴复制好的 JSON（或按窗口提示逐项填入）并保存。
     推荐同时导入 skills\consumer-cad\SKILL.md 作为技能。
   - 其他支持 MCP 或工作区的 Agent（Cursor / Claude Desktop / Claude Code /
     Windsurf / Cline / Antigravity / Codex 等）：
     直接粘贴 mcp.json 内容，或用 Agent 打开本解压目录即可调用 .mcp.json 与 cad.cmd。

AI 对话生成的结果默认保存在 workspace 文件夹。
如果双击脚本失败，请确认 ZIP 已完整解压且当前目录可写。
更多说明见 README.md（英文见 README_EN.md），组件及许可见 docs/portable.md。
